# Ограниченный пилот NOAA GFS

Это небольшой исторический пилот независимого прогноза NOAA GFS для ветровой мощности. Он не подключает NOAA к приложению и не является полной январской валидацией.

## Воспроизведение

Из корня репозитория создайте отдельную среду; зависимости проекта не меняются:

```sh
python3 -m venv /tmp/noaa-gfs-venv
/tmp/noaa-gfs-venv/bin/pip install numpy==2.5.3 eccodes==2.48.0 eccodeslib==2.49.0.30
python3 forecast_weather.py 2026-01-15 --days 3 --cache-dir weather-cache
/tmp/noaa-gfs-venv/bin/python experiments/noaa_gfs/pilot.py \
  --input-dir /путь/к/оригинальным-csv \
  --ecmwf-dir weather-cache \
  --cache-dir /путь/вне-репозитория/noaa-gfs-cache \
  --output-dir experiments/noaa_gfs
```

Нужен интернет-доступ к публичному `noaa-gfs-bdp-pds.s3.amazonaws.com`. Скрипт читает `.idx`, выбирает только `UGRD` и `VGRD` на уровне 100 м над землёй, затем запрашивает диапазоны байтов соответствующих сообщений GRIB2 с проверкой HTTP 206 и `Content-Range`. Суммарная передача ограничена 500 MB; скачанные сообщения кешируются во внешнем каталоге. Python и точные версии пакетов записаны в `provenance.json` после завершения.

## Заранее заданная выборка

Три последовательных решения: 15, 16 и 17 января 2026 в 06:00 UTC. Для каждого используется предыдущий фиксированный цикл GFS 18:00 UTC, leads 12–35, то есть 24 целевых часа; суммарное UTC-окно 15 января 06:00 — 18 января 05:00. В индексах всех трёх циклов подтверждены поля U/V на высоте 100 м. Скорость ветра вычисляется как `hypot(U,V)` в м/с. Для каждой турбины берётся ближайшая сеточная точка без пространственной интерполяции; координаты и фактические выбранные точки приведены в provenance.

Исходная кривая мощности каждой турбины заново строится существующим `power_model.py` только на полных часах записей до 31.12.2025 включительно. Одна и та же кривая без новой калибровки применяется к GFS и ECMWF. ECMWF ×1,10 показан отдельно как уже существующий ориентир; коэффициент не переносится на GFS. На выбранных пилотных датах коэффициенты не подбираются.

Для сопоставления используется гипотеза CSV local−UTC = +5 часов; часовой пояс CSV в ТЗ не указан. Фактические мощности объединяются только с общими полными часами двух источников. В репозитории не сохраняются измерения и почасовые ошибки, чтобы исходную мощность нельзя было восстановить из прогноза и ошибки. `comparison.csv` содержит только прогнозы; `metrics.json` — агрегированные MAE, RMSE и смещение. SHA256 исходных файлов записаны в provenance.

ECMWF значения загружены из [Open-Meteo Single Runs API](https://open-meteo.com/en/docs/single-runs-api); Open-Meteo публикует архивные данные по лицензии [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). NOAA GFS выгружается из [публичного AWS Open Data bucket](https://registry.opendata.aws/noaa-gfs-bdp-pds/). Эти исходные прогнозы преобразованы в скорость ветра `hypot(U,V)`, затем в мощность существующей кривой. Результаты производные и сохраняют происхождение источников в `provenance.json`.

## Итог

Результаты по 72 общим полным часам на каждую турбину:

| Турбина | Модель | MAE | RMSE | Смещение прогноза |
|---|---|---:|---:|---:|
| 1 | NOAA GFS | 0.224643 | 0.298697 | +0.219817 |
| 1 | ECMWF | 0.085571 | 0.146230 | −0.030761 |
| 1 | ECMWF ×1,10 | 0.077446 | 0.136716 | +0.000631 |
| 2 | NOAA GFS | 0.218625 | 0.294049 | +0.213150 |
| 2 | ECMWF | 0.093691 | 0.157335 | −0.032919 |
| 2 | ECMWF ×1,10 | 0.084791 | 0.149449 | −0.001616 |

Объём скачивания — около 143 MB, включая индексы и выбранные поля. В этом 72-часовом окне GFS заметно хуже ECMWF и имеет сильное завышение мощности. Практического основания расширять проверку сейчас нет; GFS не добавляется в продукт. Это короткий пилот, а не полная январская проверка и не вывод о работе в феврале.

## Инструменты

Временная среда использовала NumPy 2.5.3 (BSD-3-Clause и включённые сторонние лицензии), ecCodes Python bindings 2.48.0 (Apache-2.0) и ecCodes 2.49.0.30 (Apache-2.0); wheel license metadata и платформа записаны в provenance. Версии закреплены в команде выше. Эти пакеты не добавлены к требованиям приложения.
