# ВЭС: воспроизводимый прогноз выработки

Прототип для задачи [«Agentic AI для прогнозирования выработки ВЭС»](https://docs.google.com/document/d/1Fn5IJoj87Fx7IAknG26zkfX8c0eq7feCujd0m66PCgY/edit) трека «Энергетика» HackAlem AI. Пользователь — аналитик ВЭС, которому нужен почасовой прогноз на 24–48 часов с известным источником погоды.

## Текущий результат

Работает первый шаг сквозного сценария: `forecast_weather.py` загружает архивный 48-часовой прогноз ECMWF для двух турбин на выбранную дату и сохраняет параметры запроса, время выпуска модели, момент принятия решения, координаты, единицы и 48 почасовых значений. Модель выработки и полный цикл agentic AI ещё разрабатываются.

## Запуск

Нужны Python 3.10+ и интернет для первого запроса. Сторонних Python-библиотек, API-ключей, БД и Docker пока нет.

```sh
python3 forecast_weather.py 2026-02-01
```

Ожидаемый результат: две строки `turbine-1/2: 48 hours...`; ответы сохраняются в `weather-cache/`. Повторный запуск той же команды читает кеш, включая параметры исходного запроса. Кеш не включается в Git. При ошибке API или неполных 48 часах команда завершится с кодом 1 и понятной ошибкой. Даты задаются в UTC; пример выше использует прогноз модели 31.01.2026 18:00 UTC для решения 01.02.2026 06:00 UTC, с 12-часовым зазором. Документация Open-Meteo указывает типичную задержку публикации глобальных запусков 4–6 часов. Для точного доказательства времени доступности конкретного запуска потребуются метаданные провайдера.

## Архитектура

`forecast_weather.py` — клиент Open-Meteo Single Runs API и валидатор целостности погоды. Источник: ECMWF IFS HRES 9 км. Два CSV организатора с 10-минутными измерениями будут агрегированы до часов; затем будет обучена модель мощности и добавлен ежедневный процесс прогноза. Погодные данные сохраняются в JSON с URL запроса для воспроизводимости.

## Проверка

```sh
python3 forecast_weather.py 2026-02-01
python3 forecast_weather.py bad-date  # ожидаемая ошибка и код 1
```

Фактически проверено 23.09.2026: обе турбины вернули по 48 часов для 01.02.2026. Полное покрытие февраля и обучение модели ещё не проверены. Доступ к ключевой погодной функции не требует личного аккаунта участника.

## Данные, источники и ограничения

Два CSV организатора с историей до 31.01.2026 хранятся локально и не включены в Git до проверки правил обращения с данными. Текст ТЗ и анализ данных собраны в локальной `/Users/arch/projects/task/`. Источники и условия использования — [docs/SOURCES.md](docs/SOURCES.md). История часов — [docs/PROGRESS.md](docs/PROGRESS.md).

Точность февральской выработки без фактических февральских значений пока нельзя измерить. Планируется честная январская проверка: обучение до января, прогнозная погода за январь, сравнение с фактом, затем переобучение до конца января.
