# Предварительная проверка модели на январе 2026

Проверено 23.09.2026. Два CSV с десятиминутными измерениями преобразованы в полные часы: по шесть записей на час. Отдельные сглаженные кривые мощности для турбин обучены **только до 31.12.2025 включительно**. Для 01–14.01.2026 использованы архивные прогнозные запуски ECMWF IFS HRES, доступные до времени решения; вход модели — прогноз ветра на высоте 100 м. Для каждого часа выбран последний уже сформированный ежедневный прогноз. Фактическая январская мощность использована только для оценки.

Часовой пояс меток CSV в ТЗ не указан. Поэтому расчёт приведён для трёх гипотез: локальное время CSV минус UTC равно 5, 6 или 7 часам. Сравнение температуры датчика с архивной прогнозной температурой за 1–14 января дало лучший сдвиг около 7 часов, но этого недостаточно, чтобы считать его доказанным часовым поясом. Сдвиг 7 часов может включать систематическую задержку/ошибку источников.

| 2 | +6 | 324 | 0.1496 | 0.2882 | −0.0796 |

Единица ошибок — нормализованная активная мощность в диапазоне 0–1. *Константа — среднее значение мощности на обучающем периоде до 31.12.2025, рассчитанное на тех же сопоставленных часах. Это простой ориентир, а не сильный конкурентный прогноз. Знак смещения — прогноз минус факт: отрицательное значение показывает систематическое занижение. Высота измерения ветра турбиной не задана; использование прогнозного ветра 100 м вместо датчика создаёт сдвиг входных данных.

Повторить проверку при наличии двух CSV организатора:

```sh
python3 forecast_weather.py 2026-01-01 --days 14
python3 power_model.py train --input-dir /path/to/csv --cutoff 2025-12-31 --output model.json
python3 validate_january.py --model model.json --input-dir /path/to/csv --last 2026-01-14
```

После оценки итоговая модель `models/power-curve-2026-01-31.json` отдельно переобучена на всех доступных измерениях до 31.01.2026. Фактической выработки за февраль в предоставленных файлах нет; приведённые цифры относятся только к январю.
