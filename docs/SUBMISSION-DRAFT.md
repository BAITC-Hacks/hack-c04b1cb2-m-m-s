# Черновик подачи на платформе

**Статус:** форма «Сдать решение» ещё не отправлена. По инструкции организатора после публикации GitHub нужно отдельно заполнить название и описание проекта на [странице трека](https://edu.astanahub.com/hackathons/df4743f5-c492-415c-b45a-1f13adb78e06?tab=tracks). Решение можно обновлять до дедлайна. Перед отправкой проверить актуальные объявления и поля формы.

**Название:** ВЭС — прогноз, который можно проверить

**Описание для формы:**

> Почасовой прогноз двух турбин на 48 часов с проверяемым происхождением: архивный выпуск ECMWF, момент решения и граница обучения. В репозитории — 29 ежедневных прогнозов и все 672 часа февраля. Локальная демонстрация запускается одной командой без ключей и аккаунтов.
>
> Система выбирает архивный прогноз погоды по координатам, проверяет входы, применяет обученные на истории модели мощности и анализирует результат. Режим наблюдения самостоятельно проверяет входы заданной исторической даты и пересчитывает прогноз при изменении погоды или артефакта модели; при сбое сохраняет последний успешный результат. Обновление, восстановление и повторный старт проверяются тестом без сети. Интерфейс показывает происхождение расчёта и ссылки на погодные входы; просмотр опубликованных результатов работает офлайн. Январская оценка выполнена с разделением подбора и проверки поправки. Выход — нормализованная активная мощность 0–1; февральская ошибка без фактических измерений неизвестна. Точное историческое время публикации каждого погодного выпуска не подтверждено; принят 12-часовой запас относительно момента решения.

**Репозиторий:** [BAITC-Hacks/hack-c04b1cb2-m-m-s](https://github.com/BAITC-Hacks/hack-c04b1cb2-m-m-s).

Перед финальной подачей проверить последний commit в `main`, запуск из свежего клона, доступность 29 JSON и CSV, и соответствие текста фактически опубликованной версии. Git push без формы не считается сдачей.
