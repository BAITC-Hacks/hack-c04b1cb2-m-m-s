**Название:** ВЭС Forecast Agent — воспроизводимый прогноз выработки

**Описание для формы:**

> Система автоматически воспроизводит ежедневный почасовой прогноз двух турбин ВЭС на 31 января — 28 февраля 2026 года. Для каждой даты она выбирает архивный прогноз ECMWF, который мог быть доступен на момент решения, проверяет 48 часов погоды, применяет обученные на исторических данных модели мощности двух турбин и анализирует результат. В репозитории опубликованы 29 ежедневных прогнозов и сводный CSV на 672 часа февраля. Январская проверка и ограничения описаны в README. Демонстрация запускается локально одной командой `python3 web.py` без ключей, личных аккаунтов и интернета для просмотра готовых результатов. Выход — нормализованная активная мощность 0–1; установленная мощность в ТЗ не указана.

**Репозиторий:** [BAITC-Hacks/hack-c04b1cb2-m-m-s](https://github.com/BAITC-Hacks/hack-c04b1cb2-m-m-s).

Перед финальной подачей проверить последний commit в `main`, запуск из свежего клона, доступность 29 JSON и CSV, и соответствие текста фактически опубликованной версии. Git push без формы не считается сдачей.
